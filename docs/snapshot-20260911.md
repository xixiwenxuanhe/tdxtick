# 快照：2026-09-11 收盘前 —— 逐笔成交 + 逐笔委托（任意股，程序化）

## 已验证可用
- 历史（任意股+任意日，毫秒、含订单号）：`tdxapi.cli history <code> <date>`
- 实时成交（任意股，无需视图/点击）：`tdxapi.cli live <code>` / `live.snapshot(channel='trade')`
- 实时委托（任意股，程序化切股；需"逐笔委托明细"视图打开一次）：
  `tdxapi.cli orders <code>` / `orders.fetch_orders(code)`
- 实测：000001 / 600519 / 000759 均成功。

## 协议要点（详见 DECODER_TASK.md）
- 成交：轮询 0x0550 / 数据 0x0554；委托：轮询 0x0555 / 数据 0x055e
- 请求带 6 位股票代码 + seq(u32)；数据帧密钥 = XOR 0x49（增量），批量响应为 zlib
- 内存：成交 obj@+0x79bd0b(#0x250/#0x348)，委托 obj@+0x760a80(#0x254/#0x3d0)，记录 20B
